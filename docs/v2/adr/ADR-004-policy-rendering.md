# ADR-004: 정책 원문을 `AGENTS.md`/`CLAUDE.md`에 적용하는 방식
- 상태: 승인(2026-11-05)
- 관련: D-04, R-5
- 날짜: 2026-11-05

## 배경
Claude Code는 `CLAUDE.md`가 있으면 `AGENTS.md`를 읽지 않는다(02 매트릭스 CC-MEM). 그래서 `claude`나 `both` 설치에서 `CLAUDE.md`를 만들면 기존 `AGENTS.md`의 정책이 Claude에 전달되지 않는다(R-5).

## 선택지
1. `shared/policies/*.md`에서 렌더링해 두 파일 각각의 관리 구간에 쓴다.
2. `CLAUDE.md` 구간에 `@AGENTS.md` import를 쓴다. (문서상 유효하다. 그러나 claude 단독 설치에는 AGENTS.md가 없을 수 있고, 사용자가 AGENTS.md를 지우면 정책도 사라진다.)

## 결정
**선택지 1.** 렌더러는 에이전트별 차이(도구 이름, 스킬 경로, `/skills`↔`/mcp` 안내)만 치환한다.
- 기존 경로의 `AGENTS.md` 구간은 기존 텍스트를 그대로 쓴다. 렌더러를 거치더라도 바이트 단위로 같아야 한다.
- `both` 설치에서는 두 파일에 같은 정책이 들어간다. 그래도 Claude는 CLAUDE.md만 읽으므로 같은 정책이 두 번 로드되지 않는다.

## 근거
- 설치 조합과 관계없이 한 가지 방식으로 동작한다.
- import 체인(최대 4단계)이나 사용자 파일 상태에 의존하지 않는다.

## 결과와 위험
- 테스트: restricted 경로의 렌더 결과가 기존과 같은지, `claude` 단독 설치에 AGENTS.md가 없어도 정책이 들어가는지.
- 위험: 두 파일의 정책 문구가 어긋날 수 있다 → 같은 원문에서 렌더하고 테스트로 비교한다.

## 되돌리는 방법
렌더러 대신 import 한 줄을 쓰도록 템플릿만 바꾸면 된다.
