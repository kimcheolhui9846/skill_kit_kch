# ADR-005: JSON 설정의 소유권 관리
- 상태: 승인(2026-11-05)
- 관련: D-05, REQ-USER-002
- 날짜: 2026-11-05

## 배경
JSON 설정 파일(`.mcp.json`, `.claude/settings.json`, user 범위 `~/.claude/settings.json`)에는 주석을 쓸 수 없어서 관리 구간 마커를 쓸 수 없다.

## 선택지
1. 매니페스트에 키트가 소유한 JSON 포인터(RFC 6901)와 값의 sha256을 기록하고, 그 키만 수정·삭제한다.
2. 파일 전체를 키트가 소유한다(기존 사용자 파일과 충돌한다).
3. 별도 파일(`settings.kit.json`)을 둔다(Claude가 읽지 않는다).

## 결정
**선택지 1.**
- 같은 포인터에 키트 소유가 아닌 값이 이미 있으면 `CONFLICT`(종료 코드 2)다.
- 키트가 마지막으로 쓴 해시와 현재 값이 다르면 사용자가 고친 것으로 보고 `CONFLICT`다.
- 저장할 때 키 순서는 dict 순서(Python 3.7+)로 보존한다. 들여쓰기(2칸/4칸/탭)는 기존 파일에서 추정하고, 줄바꿈은 원본 형식을 따른다.
- 쓰기 전에 백업한다(D-06/D-18).
- 배열(`permissions.allow` 등)은 키트가 넣은 **원소 값의 해시** 단위로 소유한다.

## 근거
기존 해시 기반 소유 판정(`kit/plan.py:73-96`)을 JSON 키 단위로 넓힌 것이라 개념이 같다.

## 결과와 위험
- 테스트: 키 순서와 들여쓰기 보존, 사용자 키 불변, 충돌 탐지, 제거할 때 키트 키만 삭제.
- 위험: JSON 포맷 세부(키 뒤 공백 등)는 완벽하게 보존할 수 없다 → `json.dumps`로 다시 직렬화한다는 점을 문서화한다.

## 되돌리는 방법
JSON writer 모듈 하나만 바꾸면 된다.
