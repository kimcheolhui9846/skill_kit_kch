# ADR-014: 새 경로의 네트워크 동작 확인
- 상태: 승인(2026-11-05)
- 관련: D-14, Q3
- 날짜: 2026-11-05

## 배경
네트워크를 쓰는 작업은 MCP 패키지 확인(`npx`/`uvx`), 도구 설치, `source add`의 GitHub 접근(D-21)이다.

## 선택지
1. 원문안: plan에 네트워크 동작을 모두 표시한다. TTY면 확인을 묻고, 비대화형이면서 `--yes`가 없으면 `SKIPPED`로 처리한다.
2. 항상 실행하고 `--offline`으로만 끈다(기존 경로 방식).

## 결정
**새 경로는 선택지 1, 기존 경로는 기준선 동작을 유지한다.**
- Q3에 따라 기존 경로의 user 범위 도구 설치(`kit/tools.py:59-66`)는 예외로 유지한다.
- 새 경로에서는 같은 설치를 `user-scope install [network]`로 표시한다.

## 근거
원문 권장안과 검토자 결정 Q3.

## 결과와 위험
- 테스트: 비대화형에서 `--yes`가 없으면 네트워크 항목이 SKIPPED이고, 종료 코드는 0이며, 보고서에 표시된다.

## 되돌리는 방법
확인을 묻는 기본값 상수만 바꾸면 된다.
