# ADR-007: 프로필 스키마 v2와 조합 문법
- 상태: 승인(2026-11-05)
- 관련: D-07, REQ-PROF-002/003
- 날짜: 2026-11-05

## 배경
v1의 `extends`는 문자열 하나만 받고, 병합하는 리스트도 4종뿐이다 [확인됨: `kit/profiles.py:16,57-59`].

## 선택지
1. v2 스키마(원문 §7.4: `extends` 배열, `packs`, 에이전트별 항목)에 CLI `--profile a,b` 조합 문법을 더한다.
2. v1을 유지하고 팩을 별도 옵션으로 받는다.

## 결정
**선택지 1.** v1 파일은 읽을 때 v2로 정규화한다. 기존 5개 프로필 파일은 v1 그대로 둔다.

## 근거
원문 권장안이다. 조합 문법이 팩(D-08)과 자연스럽게 맞는다.

## 결과와 위험
- 테스트: v1→v2 정규화 결과가 기존 병합 결과와 같은지(기존 5개 프로필).
- 위험: 다중 상속의 순서와 충돌 규칙 → 왼쪽부터 병합하고 중복은 제거한다(04_DESIGN에 명시).

## 되돌리는 방법
v1 경로가 남아 있으므로 v2 로더만 끄면 된다.
