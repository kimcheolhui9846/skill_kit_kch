# ADR-020: 사용자 목록 우선 규칙과 경로 분리
- 상태: 승인(2026-11-05)
- 관련: D-20, REQ-SRC-007, REQ-COMPAT-002, R-3
- 날짜: 2026-11-05

## 배경
검토자는 기존 스킬과 겹치면 사용자 목록의 버전이 우선하기를 원한다. 그러나 restricted 경로는 기존 11개를 그대로 설치해야 한다.

## 선택지
1. 경로를 분리한다: 새 경로는 사용자 목록을 우선하고, restricted 경로와 미러는 바꾸지 않는다.
2. 기존 스킬을 사용자 목록 버전으로 교체한다(호환성 위반).

## 결정
**선택지 1.**
- 겹침은 쌍별로 판정해 `07_SOURCES_EVALUATION.md`에 기록한다. 처리는 다음 중 하나다:
  - `replace-in-standard`: 새 경로의 팩에서 기존 스킬을 뺀다
  - `merge-unique`: 기존 스킬의 고유한 부분만 overlay로 남긴다
  - `keep-both`: 두 스킬의 범위가 다르다
- 나중에 D-21로 추가하는 주소도 같은 우선순위를 갖는다.

## 근거
검토자 결정(설계 단계)과 R-3.

## 결과와 위험
- 테스트 V-22: restricted 경로의 설치 트리와 미러가 기준선과 같은지.

## 되돌리는 방법
카탈로그의 팩 배정만 되돌리면 된다.
