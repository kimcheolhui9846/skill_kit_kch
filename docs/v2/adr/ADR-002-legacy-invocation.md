# ADR-002: 기존 호출(서브커맨드 없음)의 의미
- 상태: 승인(2026-11-05)
- 관련: D-02, REQ-COMPAT-001
- 날짜: 2026-11-05

## 배경
`kit/cli.py:36-65`의 argparse는 위치 인수를 받지 않는다. 기존 호출은 모두 `--profile`, `--target` 같은 옵션만 쓴다.

## 선택지
1. 첫 토큰이 알려진 서브커맨드(`install`, `plan`, `verify`, `uninstall`, `source`, `task`, `capture`, `report`, `recover`)면 새 경로로, 아니면 기존 파서로 보낸다.
2. 모든 호출을 새 파서로 옮기고 기존 옵션은 별칭으로 둔다. (위험: 도움말, 오류 문구, 종료 코드가 미세하게 바뀐다.)

## 결정
**선택지 1.** 서브커맨드가 없는 호출은 기존 `kit/cli.py` 경로를 **그대로** 탄다. 의미상 `install --agent codex --policy restricted`와 같고, 결과는 기준선과 바이트 단위로 같아야 한다(정규화 규칙 제외).

## 근거
- 기존 파서가 위치 인수를 받지 않으므로, 첫 토큰으로 판정해도 기존 입력과 충돌하지 않는다 [확인됨: `kit/cli.py:36-65`].
- 기존 코드 경로를 건드리지 않는 것이 REQ-COMPAT-001을 지키는 가장 확실한 방법이다.

## 결과와 위험
- P3-T1 골든 테스트(기준선 24개 스냅샷)가 이 동일성을 강제한다.
- 위험: 공통 코드를 Adapter로 추출하면 기존 경로가 간접적으로 바뀔 수 있다 → 추출하기 전에 골든 테스트를 먼저 만든다(R-1).

## 되돌리는 방법
분기 함수 하나를 지우면 기존 동작만 남는다.
