# ADR-013: CLI 진입점
- 상태: 승인(2026-11-05)
- 관련: D-13
- 날짜: 2026-11-05

## 배경
`pyproject.toml`이 `package = false`라서 콘솔 스크립트가 없다. 진입점은 `bootstrap.sh`/`bootstrap.ps1`/`python -m kit`이다.

## 선택지
1. 기존 진입점에 서브커맨드를 추가하고, `kit` 명령은 README에서 사용자 함수/별칭으로 안내한다.
2. `package = true`로 바꿔 콘솔 스크립트를 만든다(배포 형태가 바뀌므로 별도 승인 사항).

## 결정
**선택지 1.**

## 근거
기존 설치 방식("레포를 받아 bootstrap 실행")을 바꾸지 않는다.

## 결과와 위험
- Python이 없는 셸 전용 모드는 서브커맨드를 지원하지 않고 기존 동작만 한다. 서브커맨드를 받으면 "Python 필요"라고 안내하고 64로 끝난다.

## 되돌리는 방법
되돌릴 것이 없다(기존 진입점에 추가만 한다).
