# {agent} Project Policy

## Principles
1. Analyze the requirements first: the exact inputs, outputs, constraints, and expected results.
2. Keep unconfirmed assumptions apart from confirmed facts, and label them.
3. Use only the skills the task needs; start non-trivial tasks with the task-router skill.
4. Set the verification criteria before you implement.
5. Report test results with the evidence of an actual run; never claim a test passed unless it ran.
6. Explain what each important test would catch, so its validity can be reviewed.
7. Look for counterexamples to important features before calling them done.
8. Do not start the next task without the human's approval.
9. Record the state of approved work.
10. Get approval before sending anything outside or doing anything risky.

The kit skills are in `{skill_root}/`; run /skills in {agent} to list them.
